\begin{abstract}
En este trabajo se aborda la identificación basada en datos del sistema
depredador-presa de Lotka-Volterra. Se recolectan datos mediante simulación
discretizada del modelo y se entrenan dos arquitecturas de identificación:
una Red Neuronal (NN) feedforward y un sistema Adaptativo Neuro-Difuso
(ANFIS) basado en funciones de base radial (RBF) más regresión Ridge.
Ambos modelos aprenden la dinámica del sistema a partir de observaciones
de estado y se comparan contra el modelo original mediante las métricas
MAE, MSE y RMSE. Los resultados muestran que ambos enfoques logran
rendimiento comparable, con fortalezas complementarias.
\end{abstract}

\section{Introducción}

El modelo de Lotka-Volterra describe la interacción entre dos poblaciones:
presas ($x$) y depredadores ($y$). Se rige por las ecuaciones diferenciales:

\begin{equation}
\dot{x} = a\,x - b\,x\,y \qquad
\dot{y} = c\,x\,y - d\,y
\end{equation}

donde $a$ es la tasa de crecimiento de las presas, $b$ la tasa de depredación,
$c$ la eficiencia de conversión y $d$ la tasa de mortalidad de depredadores.

\section{Metodología de Identificación}

El proceso sigue los siguientes pasos:

\begin{enumerate}
  \item Discretizar el modelo con paso $T=0.1$ usando Euler.
  \item Generar 75 trayectorias de 300 pasos variando condiciones iniciales
        y parámetros del sistema.
  \item Construir el conjunto entrada-salida:
        \[
        \mathbf{x}_k = [x_k, y_k]^\top \to \mathbf{x}_{k+1} = [x_{k+1}, y_{k+1}]^\top
        \]
  \item Entrenar los modelos NN y ANFIS sobre los datos.
  \item Evaluar en 1 paso y en trayectorias completas (50 pasos).
\end{enumerate}

Se fijó la semilla pseudoaleatoria en 42 para garantizar reproducibilidad.

\section{Red Neuronal (NN)}

Perceptrón multicapa (MLPRegressor de scikit-learn):

\begin{itemize}
  \item \textbf{Entrada}: 2 neuronas ($x_k$, $y_k$).
  \item \textbf{Capas ocultas}: 2 capas de 32 y 16 neuronas, ReLU.
  \item \textbf{Salida}: 2 neuronas ($x_{k+1}$, $y_{k+1}$).
  \item \textbf{Optimizador}: Adam, early stopping con paciencia 15.
  \item \textbf{Data augmentation}: 2 copias adicionales con ruido
        $\mathcal{N}(0, 0.5)$.
\end{itemize}

\section{ANFIS}

El sistema ANFIS implementado utiliza una rejilla fija de funciones de
base radial (RBF) para la fuzzificación, seguida de regresión Ridge:

\begin{itemize}
  \item \textbf{Capa RBF}: 9 funciones gaussianas por entrada,
        $\sigma=18$, rejilla uniforme $[10, 90]$ $\to$ 81 reglas.
  \item \textbf{Normalización}: fuerzas de disparo normalizadas a suma 1.
  \item \textbf{Regresor}: Ridge con $\alpha=0.15$, solución analítica
        -- entrenamiento instantáneo ($<0.1$ s).
\end{itemize}

Este diseño corresponde a un ANFIS de orden cero (consecuentes constantes)
con premisas fijas no entrenables.

\section{Conclusiones}

\begin{itemize}
  \item La NN ofrece el mejor error 1-paso (MAE 0.531) y el mejor promedio
        de trayectoria (MAE 7.13), pero con alta variabilidad entre CIs.
  \item El ANFIS (RBF+Ridge) ofrece entrenamiento instantáneo, error 1-paso
        competitivo (MAE 0.836) y la máxima consistencia entre CIs
        (desviación estándar 0.8 frente a 4.8 de la NN).
  \item Las rejillas RBF más densas (9 MF, $\sigma=18$) son clave para
        cubrir uniformemente el espacio de estados y evitar la degradación
        en condiciones iniciales extremas.
  \item Las métricas MAE, MSE y RMSE cuantifican objetivamente el
        desempeño de cada modelo.
  \item Como trabajo futuro, estos modelos identificados pueden servir
        como base para el diseño de controladores en la Parte 3.
\end{itemize}
